## ✨ מה יש באתר
- **עמוד הבית:** פסל חי שמורכב מחלקים מהפוסטר של הפסטיבל, מתערבב לבד ומחליף את צבע הרקע.
- **קול קורא:** הסבר על הפסטיבל, על המקום ועל אפשרויות המיקום (חלל בית הכנסת המרכזי, גלריה 1/2, פטיו, או הצעה פתוחה).
- **טופס הגשה בשלבים:** פרטים אישיים, הפרויקט, תיק עבודות (חובה), אינסטגרם או אתר, והעלאת קבצים. הטיוטה נשמרת בדפדפן ונשלחת בבטחה.
- **ממשק ניהול:** רשימת ההגשות עם סטטוסים, ייצוא ל-CSV, עריכת כל הטקסטים באתר (טיוטה ← תצוגה מקדימה ← פרסום), משתמשים וסטטיסטיקה.
- **מדיניות פרטיות והצהרת נגישות** מלאות.

## 🛠️ איך זה בנוי
- **האתר:** React 19, ‏TypeScript, ‏Tailwind CSS ו-Vite, בתיקייה [`site/`](site).
- **השרת:** פונקציות Serverless ב-Vercel, בתיקייה [`site/api/`](site/api).
- **מסד הנתונים:** Neon Postgres, באזור פרנקפורט.
- **אחסון:** Vercel. העלייה לאוויר נעשית מתוך `site/` בפקודה `npx vercel deploy --prod --yes`, ורק אחרי אישור מפורש של אורי.

## 🚀 הרצה מקומית
```bash
cd site
npm install
npm run dev   # http://localhost:5273
```
במחשב המקומי אין חיבור לשרת. טופס ההגשה עובד שם במצב הדגמה בכתובת `/c/1/apply`. ההוראות המלאות, כולל משתני הסביבה, נמצאות ב-[`site/SETUP.md`](site/SETUP.md) וב-[`HANDOFF.md`](HANDOFF.md).
