# הקמה והפעלה: אתר מדורות 2027

## מה רץ איפה
- **האתר** (Vite + React) ו**פונקציות השרת** (`api/`) רצים ב-Vercel, בפרויקט `medorot-2027`.
- **מסד הנתונים** הוא Neon Postgres (תוכנית חינמית, פרנקפורט). הוא חובר דרך ה-Marketplace של Vercel, ולכן משתני הסביבה (`DATABASE_URL` ועוד) מוגדרים בפרויקט אוטומטית.
- **הקבצים המצורפים** נשמרים במסד הנתונים עצמו, בטבלת `application_files`. הם פרטיים, ואין להם שום כתובת ציבורית.
  - **קבצים רגילים:** עד 4MB לקובץ.
  - **תמונות:** עד 30MB, כי הדפדפן מקטין אותן לפני ההעלאה.
  - **סרטונים ארוכים:** מוגשים כקישור.
- **התראות למייל של הצוות** נשלחות דרך Resend. זה לא חובה, וגם בלי זה ההגשה נשמרת.

## איך הגשה נשמרת
1. **`POST /api/applications/start`:** השרת בודק את כל השדות מחדש (אותה סכמת zod כמו בדפדפן), את מלכודת הבוטים ואת הגבלת הקצב, ויוצר טיוטה. מזהה הטיוטה הוא מפתח שהדפדפן יוצר, ולכן ניסיון חוזר לא יוצר הגשה כפולה.
2. **`PUT /api/applications/file`:** בקשה אחת לכל קובץ, עם המפתח בכותרת. השרת בודק את סוג הקובץ ואת הגודל המדויק שלו.
3. **`POST /api/applications/complete`:** השרת מוודא שכל הקבצים הגיעו במלואם, מסמן את ההגשה `new` ושולח מייל לצוות.
   - רק אחרי זה מוצג למגיש "ההצעה שלכם בדרך אלינו".
   - אם המייל נכשל, זה נרשם ב-`notification_error` וההגשה לא נמחקת.

כל שינוי סטטוס נרשם ב-`application_status_history`. התשובות המקוריות נעולות אחרי ההגשה, ותיקונים נרשמים בנפרד ב-`application_corrections`.

## מערכת הניהול (`/admin`)
- **כניסה:** אימייל וסיסמה. סיסמאות נשמרות מוצפנות (scrypt), והסשן נשמר בעוגייה HttpOnly ל-14 יום.
- **הגנות:** אין הרשמה עצמית. כל פעולת כתיבה מחייבת כותרת `x-medorot`, וניסיונות כניסה מוגבלים ל-8 ברבע שעה מכל חיבור.
- **סיסמת צוות:** בכניסה הראשונה ל-`/admin` קובעים סיסמה אחת לכל הצוות, ואיתה נכנסים בלי מייל.
  - **החלפה:** בעמוד "סיסמה". אחרי ההחלפה, מכשירים אחרים מתנתקים.
  - **משתמשים אישיים (אופציונלי):** מזמינים ב-`/admin/users`. הם נכנסים עם מייל וסיסמה משלהם.
- **שימושיות (`/admin/analytics`):** סטטיסטיקה אנונימית מ-`/api/track`, בטבלת `analytics_events`.
  - **מה נאסף:** צפיות לפי עמוד, מקורות הגעה, מכשיר, עיר ומדינה, משפך הטופס, פעולות (ערבוב הפסל, צפייה בצילומים, אינסטגרם) ומי באתר עכשיו.
  - **פרטיות:** בלי עוגיות ובלי IP. המזהה של מבקר מתחלף כל יום, ומי שהגדיר Do Not Track או GPC לא נספר.
  - **שמירה:** עד 13 חודשים.
- **תפקידים:**
  - **מנהל.ת:** הכל.
  - **עורך.ת תוכן:** עריכת התוכן, ופרסום רק אם מסומן.
  - **בודק.ת הגשות:** הגשות, קבצים, סטטוסים, הערות ותיקונים.
- **ניהול תוכן:** טיוטה ← תצוגה מקדימה (`/?preview=<id>`) ← פרסום. כל גרסה נשמרת בהיסטוריה, ואפשר לשחזר אותה כטיוטה.
  - **תמונות:** נשמרות בטבלת `media_assets` ומוגשות מ-`/api/media?id=`.
- **גיבוי:**
  - **נתוני ההגשות:** "ייצוא ל-CSV" בעמוד ההגשות.
  - **קבצים:** אפשר להוריד כל קובץ מעמוד ההגשה.
  - **מסד הנתונים כולו:** Neon שומר היסטוריה, ואפשר לשחזר ממנו לנקודת זמן (Vercel → Storage → Neon).
- **בדיקות מול האתר החי:** `node dev/e2e-submit.mjs` ו-`node dev/e2e-admin.mjs` מוחקות את כל מה שהן יוצרות.

## משתני סביבה (Vercel → Settings → Environment Variables)
| משתנה | מצב |
|---|---|
| `DATABASE_URL` ושאר משתני `POSTGRES_*`/`PG*` | הוגדרו אוטומטית על ידי Neon |
| `APPLICATIONS_OPEN` | אופציונלי. `false` סוגר את הטופס בלי פריסה מחדש |
| `IP_HASH_SALT` | אופציונלי. מחרוזת אקראית להגבלת הקצב |
| `RESEND_API_KEY`, `RESEND_FROM`, `NOTIFY_EMAIL`, `SITE_URL` | להתראות במייל. דורש חשבון Resend ודומיין מאומת |

## מסד הנתונים
- **הסכמה:** `db/migrations/001_init.sql`. היא כבר הורצה על מסד הנתונים.
- **שינוי עתידי:** מוסיפים קובץ `002_….sql` ומריצים:
  ```
  npx vercel env pull .env.production.local --environment=production
  node dev/migrate.mjs
  ```
- **בדיקה מלאה מול האתר החי:** הסקריפט שולח הגשה, מאמת אותה במסד הנתונים ומוחק אותה בסוף.
  ```
  node dev/e2e-submit.mjs
  ```
- **שימו לב:** הקובץ `.env.production.local` מכיל סודות. הוא נשאר רק במחשב, ו-`.vercelignore` מונע את העלאתו בפריסה.

## פיתוח מקומי
```
npm install
npm run dev                          # בלי שרת: הטופס יציג "ההגשה עוד לא נפתחה"
MOCK_API=1 npm run dev               # שרת מדומה בזיכרון, לבדיקת כל זרימת ההגשה
```
- `/concepts` היא גלריית חמשת הכיוונים, שנשמרת לעיון.
- `/c/1` עד `/c/5` הם הקונספטים עצמם.

## פריסה
```
npx vercel deploy --prod
```
- הפקודה רצה מתוך התיקייה `site`.
- `vercel.json` מגדיר את הכותרת `noindex`. מסירים אותה ביום ההשקה.
